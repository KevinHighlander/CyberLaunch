# CLIM Roadmap

## Operation Genesis — Foundation
- Project structure
- Typed intelligence event model
- Source registry
- SQLite storage
- RSS ingestion
- Significance scoring
- Watch-area classification
- Automated tests

## Operation Sentinel — Collection
- Government and defense collectors
- Resilient HTTP collection
- Source health checks
- Collection scheduling
- Structured provenance

## Operation Watchtower — Intelligence
- Event correlation
- Confidence scoring
- Source corroboration
- Contradiction detection
- Historical baselines
- Escalation-state tracking

## Operation Atlas — Presentation
- Web dashboard
- Regional watch pages
- Interactive map
- Event timelines
- Evidence views
- Analyst brief generation

## Operation Oracle — AI Analyst
- AI-assisted summarization
- Evidence-grounded explanations
- Cross-source synthesis
- Analyst queries
- Guardrails against unsupported claims

## Operation Aegis — Advanced Analysis
- Cyber/physical correlation
- Trend detection
- Anomaly detection
- Scenario indicators
- Predictive experiments with explicit uncertainty
