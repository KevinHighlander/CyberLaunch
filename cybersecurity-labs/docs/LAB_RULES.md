# Lab Rules

## Authorization checklist

Complete this before every lab:

- [ ] I own each target or have explicit permission to test it.
- [ ] I recorded the exact IP addresses, hostnames, and applications in scope.
- [ ] The activity is limited to the lab instructions.
- [ ] The lab network is isolated from production, school, and workplace networks.
- [ ] I have a snapshot or backup where a change could affect availability.
- [ ] I know how to stop the activity and restore the environment.

## Boundaries

These labs permit inventory, log review, harmless service enumeration,
integrity checks, synthetic-email analysis, and documentation. They do not
include exploitation, password attacks, credential collection, persistence,
malware, evasion, destructive actions, or testing third-party systems.

Stop immediately if:

- A target is outside the written scope.
- A command reaches the public internet unexpectedly.
- A system becomes unstable.
- Sensitive or third-party data appears.

Document what happened, disconnect the isolated lab if needed, and restore
from a known-good snapshot.
